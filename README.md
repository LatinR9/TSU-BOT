# TSU Study Bot

โปรแกรม Windows ช่วยเรียนออนไลน์: เปิดเว็บรายวิชา ให้คุณ**ล็อกอินเอง** แล้วโปรแกรมจะ
**เล่นวิดีโอบทเรียนจนจบ** และ **เปิด/เลื่อนอ่านเอกสาร** ทีละบทตามลำดับ

> โปรแกรมนี้ **ไม่ทำแบบทดสอบ ข้อสอบ หรือการบ้าน** — รายการพวกนั้นจะถูกข้ามอัตโนมัติ
> และ **ไม่เก็บรหัสผ่าน** (คุณพิมพ์เองในหน้าต่างเบราว์เซอร์ การล็อกอินถูกเก็บไว้ในโปรไฟล์เบราว์เซอร์ในเครื่องคุณเท่านั้น)

## ติดตั้ง

1. ไปที่หน้า [Releases](https://github.com/LatinR9/TSU-BOT/releases)
2. ดาวน์โหลด `TSUStudyBot-Setup-x.y.z.exe` แล้วดับเบิลคลิกติดตั้ง
   (ถ้า Windows ขึ้น SmartScreen ให้กด “ข้อมูลเพิ่มเติม” → “เรียกใช้ต่อไป”)
3. เปิดโปรแกรมจากไอคอน **TSU Study Bot** บนเดสก์ท็อป

## วิธีใช้

1. วาง **ลิงก์หน้ารายวิชา** (หน้าที่มีรายการบทเรียน) ในช่องด้านบน
2. กด **1 เข้าสู่ระบบ** → หน้าต่างเบราว์เซอร์จะเปิดขึ้น ให้ล็อกอินด้วยตัวเอง
   (โปรแกรมรอได้สูงสุด 15 นาที และจะไม่ปิดหน้าต่าง)
3. กด **2 เล่นวิดีโอบทเรียน** หรือ **3 เปิดเอกสาร** หรือ **ทำทั้งหมดตามลำดับ**
4. ดูความคืบหน้าในกล่อง “บันทึกการทำงาน” — กด **หยุด** ได้ตลอดเวลา

ทุกขั้นตอนใช้หน้าต่างเบราว์เซอร์เดียวกัน (ล็อกอินครั้งเดียวใช้ได้ทั้งหมด)

### ตั้งค่าเพิ่มเติม

| ตัวเลือก | ความหมาย |
| --- | --- |
| ลิงก์หน้าเข้าสู่ระบบ | ถ้าเว็บมีหน้าล็อกอินแยก (ว่างไว้ = เปิดหน้ารายวิชา) |
| เบราว์เซอร์ | อัตโนมัติ = ใช้ Microsoft Edge ก่อน (เล่นวิดีโอ MP4 ได้ครบ), ไม่มีจึงใช้ Chrome / Chromium ในตัว |
| ความเร็ววิดีโอ | บางเว็บไม่นับเวลาเรียนถ้าเร่งความเร็ว — แนะนำ 1x |
| เวลาอ่านเอกสาร | กี่วินาทีต่อเอกสาร 1 ไฟล์ |
| ข้ามบทที่เรียนจบแล้ว | ใช้สถานะ “เสร็จสิ้น” ของ Moodle |
| ลิงก์บทเรียนเอง | ถ้าค้นหาอัตโนมัติไม่เจอ ใส่ลิงก์บทเรียนเองได้ (1 บรรทัด/ลิงก์) |

ไฟล์ที่เว็บบังคับดาวน์โหลด (เช่น .pptx) จะเก็บไว้ที่ `เอกสาร\TSU Study Bot`

## รองรับเว็บแบบไหน

- **Moodle** (3.x / 4.x): อ่านรายการกิจกรรมจากหน้ารายวิชา (รวมแบบแยกหัวข้อเป็นหน้า ๆ),
  เล่นวิดีโอในหน้า Page / URL / H5P / Video Time ฯลฯ, เปิด File / Book (ทีละบท) / Folder (ทีละไฟล์),
  ข้าม Quiz / Assignment / Lesson / Feedback / Forum
- **เว็บทั่วไป**: หาลิงก์ที่ดูเป็นบทเรียน/วิดีโอ/เอกสารในส่วนเนื้อหาของหน้า
- **วิดีโอ**: HTML5 `<video>` และวิดีโอในกรอบ embed เช่น YouTube, Vimeo, H5P, Kaltura (เล่นจนจบ ไม่ข้าม/ไม่กรอ)

## อัปเดต

ด้านล่างโปรแกรมแสดงเวอร์ชันปัจจุบัน กด **เช็กอัปเดต** แล้ว **อัปเดตตอนนี้** เพื่อดาวน์โหลดและติดตั้งเวอร์ชันใหม่จาก GitHub Releases

## สำหรับนักพัฒนา

```bash
npm install          # ติดตั้ง + ดาวน์โหลด Chromium ลง ./ms-playwright
npm run app          # เปิดโปรแกรม (Electron)
npm test             # unit + e2e กับ LMS จำลอง (ต้องมี ffmpeg)
```

ออกเวอร์ชันใหม่: แก้ `version` ใน `package.json` แล้ว push tag `vX.Y.Z` —
GitHub Actions (`.github/workflows/release-windows.yml`) จะสร้าง `Setup.exe` และ `latest.yml` ให้ electron-updater

โครงสร้าง:

- `electron/` — หน้าต่างโปรแกรม (UI ภาษาไทย), IPC, ตัวอัปเดต
- `src/shared-browser.js` — หน้าต่างเบราว์เซอร์เดียว + โปรไฟล์ถาวร
- `src/login.js` — รอผู้ใช้ล็อกอินเอง แล้วตรวจว่าสำเร็จ
- `src/lms/collect.js` — หารายการบทเรียน (Moodle → แบบทั่วไป)
- `src/lms/video.js` — เล่นวิดีโอทุกตัวในหน้า (รวม iframe) จนจบ
- `src/lms/document.js` — เลื่อนอ่านเอกสาร / Book / Folder
- `src/lms/signals.js` — กฎจำแนกประเภท (แบบทดสอบ, วิดีโอ, เอกสาร)
